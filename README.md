# VELMORA

**Un universo de inversiones a tu alcance.**

VELMORA es una aplicación web educativa orientada a
personas en Colombia que desean conocer y comparar
alternativas de inversión.

## Objetivo

Presentar información clara sobre opciones de inversión,
sus requisitos, riesgos y características, permitiendo
filtrar alternativas según las preferencias del usuario.

## Tecnologías

- Backend: Python 3.12 + FastAPI
- Frontend: React + TypeScript + Vite
- Base de datos: PostgreSQL (Supabase)
- Autenticación: Supabase Auth
- Despliegue: Vercel
- Control de versiones: Git y GitHub

## Inicio rápido
